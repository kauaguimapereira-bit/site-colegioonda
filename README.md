# Colégio Onda

Site institucional desenvolvido para o Colégio Onda, com o objetivo de apresentar a instituição, sua proposta educacional, estrutura, projetos e informações para alunos e famílias.

## ✨ Sobre o projeto

O projeto foi desenvolvido com foco em uma experiência moderna, organizada e responsiva, permitindo que o site seja acessado de forma confortável em computadores, tablets e smartphones.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela:

- 💻 Desktop
- 📱 Smartphone
- 📲 Tablet
